## Репозиторий содержит логику хранения данных для антискам-тренажёра.

---

## Что входит в репозиторий

### `internal/storage/` — реализация хранилищ

| Папка | Описание |
|---|---|
| `postgres/` | Реализация на PostgreSQL для production |
| `memory/` | Реализация в памяти для тестов и локального демо |
| `attempttest/` | Контрактные тесты, проверяющие поведения хранилищ |

**Ключевые файлы:**

- `attempt_repository.go` — CRUD попыток, транзакции, оптимистичная блокировка
- `attempt_mapper.go` — маппинг домена в JSONB и обратно
- `progress_repository.go` — чтение сырых фактов для прогресса
- `profile_repository.go` — управление анонимными профилями
- `scenario_archive_repository.go` — синхронизация версий сценариев
- `errors.go` — разбор ошибок PostgreSQL
- `pool.go` — пул соединений, таймауты, ping

### `migrations/` — миграции базы данных

| Файл | Описание |
|---|---|
| `00001_profiles.sql` | Анонимные профили пользователей |
| `00002_scenario_versions.sql` | Архив версий сценариев (SHA-256) |
| `00003_attempts.sql` | Попытки прохождения, оптимистичная блокировка |
| `00004_attempt_decisions.sql` | Решения пользователей (JSONB) |

## Моя роль в проекте

### Что я делаю

- **Проектирую схему данных** — структура таблиц, индексы, ограничения целостности
- **Реализую хранилища** — PostgreSQL для продакшена, in-memory для тестов
- **Обеспечиваю долговечность** — данные переживают перезапуск приложения
- **Гарантирую атомарность** — попытка и её решения сохраняются в одной транзакции
- **Защищаю от конкурентных обновлений** — оптимистичная блокировка через `version`
- **Обрабатываю ошибки базы** — перевод кодов PostgreSQL в доменные ошибки
- **Пишу миграции** — версионирование схемы через goose
